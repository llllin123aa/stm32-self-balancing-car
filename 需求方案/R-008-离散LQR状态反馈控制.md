# R-008：离散 LQR 状态反馈控制

## 1. 目的

以离散时间线性二次型调节器（LQR）替换当前“角度 PID → 速度 PID → 转向 PID”中负责**纵向平衡与速度控制**的串级 PID。LQR 使用车体姿态与车轮运动状态的联合反馈，在同一控制律中权衡倾倒风险、速度误差、位移漂移和电机输出强度。

本需求建立在 R-003 卡尔曼姿态估计之上；卡尔曼输出的俯仰角和去偏角速度是 LQR 的姿态状态来源。转向控制仍保留现有差速 PID，左右轮 PWM 的混合方式不变。本需求不包含 LQR 在线求解、Flash 参数持久化、低电压增益调度或通信协议重构。

## 2. 范围与非范围

| 项目 | 本需求范围 | 说明 |
| --- | --- | --- |
| 纵向平衡 | 是 | 用离散 LQR 输出平均 PWM。 |
| 速度/位移参考 | 是 | 将遥控速度指令限加速度后积分为位置参考，形成可追踪的状态参考。 |
| 转向 | 否 | 继续用 `TurnPID` 产生 `DifPWM`，LQR 不改变转向接口。 |
| 姿态估计 | 否 | 使用 R-003 的 `AngleKalman`、去偏 Y 轴角速度；不修改卡尔曼算法。 |
| 电机混控 | 否 | 沿用 `LeftPWM=AvePWM+DifPWM/2`、`RightPWM=AvePWM-DifPWM/2`。 |
| 在线矩阵求逆/在线 Riccati 求解 | 否 | A、B、Q、R、K 全部离线产生并固化为常量。 |
| 增益调度 | 否（预留接口） | 首版只使用一组经测试的固定增益，防止电压/工作点变化叠加调试风险。 |

## 3. 前置条件与安全门槛

实施 LQR 代码前，必须满足以下条件；任意一项未满足时只能保留 PID 模式：

1. R-003 的卡尔曼模式已通过静止、扰动和故障关断测试，且 `FilterReady=1`。
2. 已标定轮径、减速比、编码器每圈脉冲数及左右轮正方向；可将编码器增量可靠换算为 m、m/s。
3. 电机正向、编码器正向、车体前倾/后倾与 IMU 符号已在轮子悬空状态逐项确认。
4. 电机输出经过统一的使能、限幅、斜坡及故障门控；倾角越限、IMU 故障或控制周期异常时 20 ms 内归零。
5. 已记录当前 PID 在同一电池、轮胎和负载下的基线日志，便于回归比较。

## 4. 状态、输入与单位约定

### 4.1 纵向状态

首版使用离散状态向量：

\[
x=[\theta,\ \dot\theta,\ s,\ v]^T
\]

| 状态 | 符号 | 单位 | 来源 |
| --- | --- | --- | --- |
| 俯仰角 | \(\theta\) | rad | `AngleKalman`，在控制入口统一由 ° 转换。 |
| 俯仰角速度 | \(\dot\theta\) | rad/s | R-003 卡尔曼的去偏 Y 轴角速度，统一由 °/s 转换。 |
| 平均轮位移 | \(s\) | m | 左右轮位移均值，使用经过方向校正的编码器累计值。 |
| 平均轮线速度 | \(v\) | m/s | 平均编码器速度，经低通/滑动窗口处理。 |

输入 \(u\) 是归一化纵向驱动命令，范围 `[-1.0, 1.0]`；执行前映射为 `AvePWM=u*PWM_MAX`。所有 LQR 矩阵、记录日志和离线脚本使用 SI 单位，只有电机接口边界允许出现 PWM 计数值。

### 4.2 参考状态

遥控速度指令先经过限速度和限加速度，得到 \(v_{ref}\)。随后以真实 `dt` 积分得到 \(s_{ref}\)：

\[
s_{ref,k}=s_{ref,k-1}+v_{ref,k}\,dt
\]

控制误差定义为 \(e=x-x_{ref}\)，其中 \(x_{ref}=[0,0,s_{ref},v_{ref}]^T\)。静止时必须将 \(s_{ref}\) 缓慢对齐当前 \(s\)，避免上电或停机后历史位置误差导致突然驱动。

## 5. 控制律与离线设计

### 5.1 离散模型

基于小车质量、轮半径、重心高度、转动惯量、轮距、电机等效增益和机械阻尼建立连续模型：

\[
\dot{x}=A_cx+B_cu
\]

使用零阶保持按实测控制周期 `dt=0.010 s` 离散化：

\[
x_{k+1}=A_dx_k+B_du_k
\]

不得把未标定的经验 PID 参数直接当作 A、B 或 LQR 增益。优先通过小幅、受限 PWM 阶跃试验识别“PWM→轮加速度”和“轮加速度→姿态”关系；模型、原始数据、拟合结果和脚本版本必须一并归档。

### 5.2 增益求解

离线脚本选择半正定 \(Q\) 与正定 \(R\)，求解离散 Riccati 方程：

\[
u_k=-K e_k,\qquad
K=(R+B_d^TPB_d)^{-1}B_d^TPA_d
\]

建议初始权重按状态单位量级归一化后再调节：姿态权重最高、角速度次之、速度与位移用于抑制缓慢漂移，`R` 用于限制 PWM 抖动。离线工具必须输出 `A_d`、`B_d`、`Q`、`R`、`K`、采样周期、模型版本、稳定性特征值和生成日期；固件仅接受该完整版本产物。

### 5.3 限幅与参考管理

LQR 本身不含积分器，因此首版不增加隐藏积分项；稳态偏差应先通过模型、轮速标定和参考前馈处理。控制链固定为：

```text
速度指令 → 限速/限加速度 → [s_ref, v_ref]
姿态卡尔曼 + 编码器 → x → u=-K(x-x_ref) → 限幅/斜坡/故障门控 → AvePWM
TurnPID → DifPWM ────────────────────────────────────────────────┘
```

- `u` 必须先限于 `[-1,1]`，再映射到 `[-PWM_MAX,PWM_MAX]`。
- 使用每周期 PWM 变化率上限，避免切换模式或通信指令突变。
- 任一状态非有限、`dt` 超出允许范围、滤波器未就绪、倾角越限或控制循环遗漏时，立刻输出零 PWM 并锁定 LQR。
- PID/LQR 模式切换仅允许在电机禁用、参考速度为零且状态稳定时进行；切换后重新清零参考状态和输出斜坡。

## 6. 软件接口与实现计划

### 6.1 新增模块

新增 `LQR.h`、`LQR.c`，至少提供：

```c
typedef struct {
    float k[4];          /* 与 [theta, theta_dot, s, v] 对应的固定状态反馈增益。 */
    float pwm_limit;     /* 平均 PWM 最大绝对值。 */
    float pwm_slew_rate; /* 每秒允许的 PWM 最大变化量。 */
    float max_speed_mps;
    float max_accel_mps2;
    uint32_t version;
} LQRConfig;

typedef struct {
    float theta_rad;
    float theta_rate_rad_s;
    float position_m;
    float velocity_mps;
} LQRState;

void LQR_Reset(LQRController *controller, float current_position_m);
uint8_t LQR_Update(LQRController *controller, const LQRState *state,
                   float requested_speed_mps, float dt_s, float *average_pwm);
```

实现中必须逐字段注明单位、坐标正方向、限幅前后值和错误返回含义。`LQR_Update()` 不得直接写电机寄存器；它只产生平均 PWM，统一执行器层负责混控和最终关断。

### 6.2 主循环/中断接入

1. 将编码器累计位置与 10 ms 轮速计算提升为与姿态一致的 100 Hz 更新；如编码器量化噪声明显，采用确定窗口长度的低通或滑动平均，并记录滤波延迟。
2. 从 R-003 卡尔曼诊断读取 `angle`、`rate`，转换为 rad、rad/s 后组装 `LQRState`。
3. 保留 `ControlMode`（PID/LQR）枚举；首版默认 PID，只有全部验收通过后才将默认改为 LQR。
4. LQR 模式下以 `AvePWM=LQR_Update(...)` 替换 AnglePID/SpeedPID 对 `AvePWM` 的写入；`TurnPID` 与左右轮混控保持原样。
5. 控制中断内不得打印、格式化字符串或解析蓝牙数据；日志由非实时任务读取快照后发送。
6. `LQRConfig`、模型版本、增益版本与固件版本必须同时写入每段日志。

## 7. 参数、日志与调试

每个控制周期记录至少包含：时间戳、`dt`、控制模式、四维状态、四维参考、四个状态误差、四个增益、未限幅 `u`、限幅后 `u`、`AvePWM`、`DifPWM`、左右 PWM、IMU/滤波器健康状态、编码器健康状态、饱和标志与故障码。

调参顺序：

1. 固定模型和采样周期，验证 A/B 的方向、可控性与离散闭环特征值全部在单位圆内。
2. 从很低 `pwm_limit` 开始，在悬空台架确认前倾/后倾时 LQR 输出方向正确。
3. 轮子落地但使用支撑架，先验证零速度平衡，再逐步提高输出限幅。
4. 仅在静止平衡稳定后加入低速速度参考；每次只改一组 Q/R 或一个模型参数版本。
5. 用与 PID 完全相同的电池电压、载荷和测试路径对比日志。

## 8. 量化验收指标

| 场景 | 指标 | 通过条件 |
| --- | --- | --- |
| 离线设计 | 可控性与闭环稳定性 | 脚本输出可控性秩为 4，全部离散闭环极点模长小于 1，并归档矩阵/版本。 |
| 台架方向测试 | 输出符号与限幅 | 前后轻推均产生恢复方向的 `AvePWM`；无反向接线；任意输入不超过 PWM 限幅。 |
| 控制周期 | 实时性 | 标称 10 ms，连续 60 s 周期偏差不超过 ±1 ms，无漏更新。 |
| 静止平衡 | 稳定性 | 在相同条件下连续 60 s 无持续振荡、无故障误触发，PWM 不连续饱和超过 1 s。 |
| 低速阶跃 | 速度跟踪 | 在预先定义的低速阶跃测试中，记录上升时间、超调、稳态误差；不得劣于 PID 基线的安全性。 |
| 抗扰动 | 恢复能力 | 轻推 10 次均不发散；每次记录峰值倾角、恢复时间和饱和时长。 |
| 故障保护 | 关断时延 | IMU/编码器失效、姿态超限、非法 `dt` 任一触发后 ≤20 ms 双电机 PWM 为 0。 |
| 模式回退 | 可恢复性 | 在禁用电机状态下可从 LQR 安全切回 PID；切换不产生 PWM 脉冲。 |

## 9. 交付物与完成定义

完成 R-008 必须同时交付：

1. 带详细注释的 `LQR.c/.h`、模式切换和统一安全门控代码；现有 PID 回退路径仍可编译、可用。
2. 可复现的离线建模/离散化/求解脚本，以及模型参数、矩阵、Q/R/K 和版本文件。
3. 编码器、轮径、减速比、电机方向标定记录；台架、静止、低速、扰动和故障测试的原始日志与结论。
4. 更新后的 Keil 工程文件、日志字段说明和调参记录。

只有全部验收指标通过，并经同条件 PID 基线回归确认没有降低安全性后，才允许将 `ControlMode` 默认值改为 LQR。
