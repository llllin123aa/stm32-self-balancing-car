# 两轮自平衡车控制系统优化总览

## 1. 现状与目标

当前工程以 MPU6050、编码器和三级 PID 实现平衡、速度与转向控制：姿态使用互补滤波，平衡环约 100 Hz，速度环约 20 Hz；控制、传感器读取和电机输出均在定时器中断中执行。

本轮优化目标是提升静态平衡、抗扰动、变速和转向时的稳定性，并确保异常时能安全停车、调试数据可复现。实施顺序应以安全、测量可信度和实时性为先，随后再替换为卡尔曼滤波和 LQR。

## 2. 建议路线图

| 阶段 | 编号 | 改进项 | 目标与验收标准 | 优先级 |
| --- | --- | --- | --- | --- |
| 基础 | R-003 | 参数与硬件标定 | 上电静止时完成陀螺零偏、加速度计零位、机械中点和左右轮方向/码盘标定；标定参数可保存、可查看。 | P0 |
| 基础 | R-004 | 安全状态机 | 实现 `待机→自检→校准→就绪→运行→故障`；倾角越限、传感器失效、低电压或通信超时后 20 ms 内关闭电机，需显式复位才可重启。 | P0 |
| 基础 | R-005 | 实时任务架构 | 设定明确采样周期与任务预算；中断只完成采样触发/数据交换，避免在中断中进行 OLED、字符串解析和阻塞式 I2C。记录控制周期抖动。 | P0 |
| 基础 | R-006 | 数据记录与回放 | 以二进制/CSV 协议输出时间戳、IMU、编码器、估计状态、控制量与故障码；可用上位机绘图并离线回放。 | P0 |
| 估计 | R-007 | 卡尔曼状态估计 | 以姿态角、角速度、陀螺零偏为最小状态；采用加速度计修正，静止/剧烈运动时根据加速度模长调整测量噪声。记录创新量和协方差以便调参。 | P1 |
| 控制 | R-008 | 离散 LQR 与增益调度 | 用状态 `[倾角、角速度、轮速/位移、转向相关状态]` 建模；离散化后离线求增益。按电池电压、速度或工作点插值调度，并在输出端加入限幅和抗饱和。 | P1 |
| 控制 | R-009 | 参考轨迹与前馈 | 速度指令经过限速度、限加速度、限加加速度；针对重力/摩擦/死区增加前馈或补偿，避免指令突变导致前倾和振荡。 | P1 |
| 驱动 | R-010 | 电机与编码器质量提升 | 标定左右轮脉冲数、减速比和方向；增加 PWM 死区补偿、起动阈值与斜坡；对低速编码器速度采用滑动窗口或观测器，降低量化噪声。 | P1 |
| 电源 | R-011 | 电池监测与降额 | ADC 采样电池电压，滤波并设欠压告警/停机阈值；在低电压时限速、限扭矩，避免 LQR 增益与实际执行能力不匹配。 | P1 |
| 通信 | R-012 | 鲁棒指令协议 | 替换直接字符串解析为带帧头、长度、命令、校验和、超时的协议；对参数范围校验，区分遥控指令与调参指令。 | P2 |
| 工程 | R-013 | 参数管理 | 将滤波噪声、LQR 矩阵/增益、机械常数和安全阈值集中到参数结构体；支持默认值、版本号、Flash 校验、恢复出厂值。 | P2 |
| 工程 | R-014 | 模块化与验证 | 将 `传感器/估计器/控制器/执行器/安全/通信` 分层；在 PC 上对滤波器、限幅和控制逻辑做单元测试或仿真，硬件上做分级测试。 | P2 |

优先级：P0 为替换算法前必须完成；P1 为核心性能改进；P2 为可维护性和扩展性改进。

## 3. 推荐实施顺序

1. 先完成 R-003 至 R-006，建立可信传感器数据、保护机制和可比较的基线日志。
2. 单独实现并验证 R-007，保留现有 PID 作为对照；先看角度误差、静止漂移和扰动恢复，确认估计器正确后再切换控制器。
3. 完成 R-008 与 R-009，先在限幅的台架/支撑架上验证，再低速落地测试；每次只修改一个工作点或一个增益组。
4. 结合测试结果完善 R-010、R-011，再实施通信、参数持久化和模块化改造。

## 4. 关键设计约束

- 控制算法必须使用实际 `dt` 或经过抖动监控的固定周期，不能在公式中散落硬编码周期。
- 所有电机输出均应经过统一的限幅、斜坡、故障切断和使能门控。
- 所有角度、角速度、速度、PWM、电压的单位必须在接口中明确，并统一记录。
- 上电与故障恢复默认禁止电机输出；传感器 ID、数据范围和通信帧均需校验。
- 卡尔曼滤波和 LQR 的初始矩阵/增益应由离线脚本生成并随测试数据版本化，避免只靠在线试错。

## 5. 分级验收建议

| 测试级别 | 验收内容 |
| --- | --- |
| 台架 | 轮子悬空：检查 IMU 符号、编码器方向、PWM 方向、输出限幅和所有故障切断。 |
| 静止 | 轮子落地但不下发速度：验证姿态漂移、零偏收敛和不倒车启动。 |
| 低速 | 小速度阶跃与缓慢转向：记录超调、稳态误差、恢复时间、电池电压。 |
| 扰动 | 轻推、载荷变化、低电压：不出现持续振荡；触发故障时可靠切断。 |
| 回归 | 固定测试脚本与日志基线比较，新的滤波器/LQR 不得降低安全性或实时性。 |
