## 使用方式

1. 每项需求使用唯一编号，例如 `R-002`。
2. 复杂需求可新建 `R-xxx-功能名称.md`，说明背景、接口、实现约束和测试方法。
3. 状态依次使用：`待确认`、`待实现`、`进行中`、`已完成`、`已取消`。
4. 实施前先确认验收标准；完成后补充测试结果。
